## Iteration 1 — PetsMap MVP bootstrap

**What was done:**
- Инициализирован greenfield-проект на Next.js 16 с App Router, TypeScript, Tailwind CSS 4 и ESLint.
- Добавлены зависимости для карты, UI и иконок: `leaflet`, `react-leaflet`, `lucide-react`, Radix UI primitives.
- Собран первый vertical slice: полноэкранная карта, моковые пины, modal-карточка, режимы просмотра/редактирования/создания.
- Реализованы блоки родословной, документа по дисплазии, фотогалереи и безопасного видео-embed для VK/RuTube.
- Добавлена базовая AI-facing документация: `AGENTS.md`, project map, frontend rules и архитектурный doc.

**Decisions:**
- Для MVP выбран `Leaflet`, чтобы не требовать API-ключ и ускорить старт.
- Данные пока загружаются из `data/mockData.json`, без backend API.
- SEO-требования выполнены только в `view`-режиме карточки: роль как `<h1>`, порода как `<h2>`.
- `iframe` ограничен доверенными URL-паттернами, ссылки на документы ограничены `http/https`.
- Галерея пока ориентирована на demo URLs с поддерживаемых HTTPS-хостов до появления реальной загрузки файлов.

**Checks:**
- `npm run lint` — OK
- `npm run build` — OK
- `npm run dev -- --port 3001` — OK, страница `/` отдалась локально
- Browser automation — недоступна в текущей среде, полноценный визуальный smoke-test не выполнен

**Next step:**
- Подключить backend/API или локальное сохранение карточек, чтобы новые пины не терялись после перезагрузки страницы.

## Iteration 2 — Pin interaction and map cleanup

**What was done:**
- Исправлена обработка клика по маркеру: клик по существующему пину больше не должен конфликтовать с общим кликом по карте.
- Базовый слой карты заменён на нейтральный светлый tile layer без спорной символики и флагов.
- Убраны пользовательские тексты уровня `mock/demo/заглушка` из карточки, формы и моковых данных.

**Decisions:**
- Для клика по маркеру добавлена защита от всплытия и фильтрация map-click по DOM-цели.
- Для карты выбран светлый слой `CARTO`, чтобы сохранить читаемость и убрать нежелательные флаги из подложки.
- В интерфейсе оставлены только пользовательские тексты, без внутренних dev-комментариев.

**Checks:**
- `npm run lint` — OK
- `npm run build` — OK

**Next step:**
- При необходимости заменить текущую подложку на собственный брендированный tile layer или self-hosted tileset.

## Iteration 3 — Modal visibility and attribution removal

**What was done:**
- Поднят `z-index` overlay и content у `Dialog`, чтобы модальная карточка отображалась поверх всех слоёв карты и верхних оверлеев страницы.
- У карты отключён attribution-control, из-за которого внизу оставалась плашка `Leaflet / OpenStreetMap / CARTO` с флагом.

- Атрибуционная плашка скрыта целиком на стороне `MapContainer`, а не только стилизована.

**Checks:**

- `npm run build` — OK

**Next step:**

## Iteration 6 — MapLibre redesign and compact modal

**What was done:**
- Карта переведена с `Leaflet` на `MapLibre GL` с визуальным стилем OpenFreeMap.
- Обновлены зависимости проекта: добавлен `maplibre-gl`, убраны `leaflet` и `react-leaflet`.
- Уменьшена верхняя часть модальной карточки, а прокрутка переведена на весь контент окна, чтобы шапка тоже уходила вверх при скролле.
- Основной экран стал компактнее: верхняя информационная плашка уменьшена, карта получила более лёгкий визуальный слой и отдельную русскоязычную подпись источника.
- Имена в родословной и остальные заметные англоязычные значения в моковых данных переведены в кириллицу.
- Документация обновлена под новый стек карты.

**Decisions:**
- Для карты выбран стиль `OpenFreeMap Liberty`, чтобы получить более современный и мягкий визуальный вид без API-ключей.
- Для прокрутки модалки использован единый контейнер `overflow-y-auto`, чтобы верхний блок больше не зависал отдельно от остального контента.
- Клички и имена в родословной переведены в кириллицу, но структура моковых данных сохранена без изменений.

**Checks:**
- `npm run lint` — OK
- `npm run build` — OK

**Next step:**
- При необходимости добавить переключатель между 2-3 стилями карты или ещё сильнее упростить верхние оверлеи главного экрана.

**Checks:**
